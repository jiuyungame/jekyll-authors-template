A category page can also be requested explicitly, and the category can come from
the folder path instead of the front matter. This file sits in
`authors-src/bob/guides/notes/`, so it hosts the category `guides/notes` and is
mirrored to `guides/notes.md`.

Use `category_page: true` when a page should *not* also be listed as a member of
its parent category — a category page is a navigation hub, not part of a chapter.
